## This implementation slice: no-repeat AutoApply recovery

Previous source and acceptance: `00697f805584fc5c16ab08b82033b8175ec9257f`, SmartPloy V4 §1.1, §4–7, §12 and `SP-V4-ONE-PROFILE-APPLY-001`.

No new dependency. Never claim a real employer was submitted by these tests.
