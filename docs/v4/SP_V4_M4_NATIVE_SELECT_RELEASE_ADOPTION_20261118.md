# SmartPloy V4 M4 — exact reviewed ordinary native employer dropdowns

**Date:** 18 November 2026. **Implementation authority:** `docs/v4/SMARTPLOY_V4_PRODUCTION_FIRST_CONTRACT.md` §§1.1, 4–7, 12 and `docs/v4/SMARTPLOY_2027_V3_APPLICABILITY_20261118.md`. **Current main baseline:** `0272a0efc1c0b104ffc2895bd9bbde37f991c099`; **first-party donor:** https://github.com/galapoto/smartploy/pull/337 at `244d23159f81d099261889179faf630ee789c191`.

## User outcome and boundaries
Keep the *existing* v0.6.0 Start AutoApply, signed-in saved profile, exact employer, current CV and letter PDFs, one-use cross-device final claim and unknown-submission recovery. The extension becomes v0.6.1, displays the exact available native `<select>` options for an ordinary required question in a real Lever/Ashby/hosted Greenhouse form, uses the existing reviewed-answer workflow and waits for native DOM settle. A saved applicant answer is prefilled **only when its value uniquely and exactly matches an enabled, currently inspected option**; changed answers are presented for applicant review, never counted as reused. The employer may receive input/change events when the user approves filling, but no final Submit is clicked by the dropdown integration.

**Never automatically choose:** legal eligibility, immigration, visa, salary, EEO, protected traits, privacy, legal assent, sensitive answer variants or ambiguous/duplicate/disabled options. Never guess boolean/synonym answers or silently retry reactive resets.
