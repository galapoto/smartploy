# SP96 — clear next action, sophisticated document review, visible private AI

## Exact scope

This is an incremental SP96 release based on the operator-proven SP95 production SHA `34681fe9763b29f0f041c45cc5993babd5d87302`. Preserve the exact CV-first gate, existing owner-scoped drafts, ATS rights and one-use employer-send protections.

### Step-by-step visibility

- `Apply for jobs`: always show one prominent, accurate **Do this next** link/action at the top:
  1. no CV → Upload CV (real file picker)
  2. CV but no method → Choose application type (anchor to three method cards)
  3. selected method but no job → Choose matching jobs (real database search)
  4. job chosen → Continue selected job / Prepare selected applications (real job area)
- Deep-link anchors to actual panels; no invented step completion or employer submission.
- Dashboard continues to open with CV → Manual/Assisted/Automatic. No auto-selected mode or background job/employer action on upload.

### CV and cover letter quality

- **NEW** isolated, deterministic, continuously rerendered `documentQuality.ts` with a `DocumentCoach` presentation shared by all 3 documents.
- Master CV: feedback on substantive content, contact route, demonstrated experience/projects, skills, education, concrete outcomes, placeholders.
- Cover letter: feedback on content, opening, exact role, exact employer, paragraphs, ending, placeholders. Explicitly **not** a qualification verifier or hiring score.
- Browser-only checks, no network/model requests, no side effects. User text remains editable. Existing master CV version history, server-backed application edits, review and export stay intact.
- UI uses SmartPloy-specific teal/paper Career Atlas palette, mobile layout and accessible feedback.

### Active private AI writing assistant

- Reuse real model status and consented `/api/v1/application-workspaces/:id/ai-suggestions` route; no new provider dependency.
- Expose **Suggest tailored wording**, **Write English letter**, **Write Finnish letter**, **Check AI connection** together in the application studio. English/Finnish letters are generated by existing approved-evidence templates even when model service is down; do not label them model output.
- Model suggestion preview allows applicant to insert **CV summary only**, **cover letter only**, or existing **both**. All remain unsaved until verified and saved; prompt/approval per action.
- Model call requires explicit per-generation user consent, and backend sends only vacancy and **approved** profile facts to the private Ollama model (not original CV file or unapproved facts).
- Do not enable unattended AI or employer POST because the user requested active assistance. No new recording of external receipts, no fabricated profile claims.
