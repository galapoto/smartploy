# Smartploy

Smartploy is a standalone job-intelligence and application orchestration product, powered by ObumAI.

The product owns job discovery, normalization, deduplication, freshness, ranking, application records, and user-facing workflow state. ObumAI remains an external reasoning and execution provider behind a stable API boundary.

This repository was initialized from the job-intelligence foundation previously prototyped inside `obumai/obumellm`. The prototype is being retired from the ObumAI monorepo rather than merged there.

See `docs/ARCHITECTURE.md` and `docs/OBUMAI_INTEGRATION.md` for the separation contract.
